# Generated site images

The four `*-editorial.webp` files in `public/images/retail/` are AI-generated illustrative assets, created on 21 October 2026. People and businesses shown are fictional; these are not customer endorsements.

| Asset | Placement |
| --- | --- |
| pharmacy-editorial.webp | Pharmaceuticals industry card |
| warehouse-editorial.webp | Warehousing industry card and authentication carousel |
| manufacturing-editorial.webp | Manufacturers industry card |
| receipt-editorial.webp | Receipt authentication carousel |

Generated with the built-in image tool after the earlier OpenArt outputs included prominent watermarks and Canva exposed only small previews. No watermark was removed. Full-size PNG originals remain in the local Codex generated-images directory. The site copies are WebP, at most 1400 pixels wide, quality 85, with no upscaling. All placements use the existing Next Image component and local public assets, without external image service dependencies.

Keep paths in `src/content/images.ts`. These assets do not change product capabilities or imply pharmacy launch readiness.
