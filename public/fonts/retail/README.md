# Retail fonts

Inter, Space Grotesk and JetBrains Mono, obtained from the existing Next.js Google Fonts cache. The CSS preserves the original subsets and weight declarations. These fonts use the SIL Open Font License.

Sources: https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/spacegrotesk, https://github.com/google/fonts/tree/main/ofl/jetbrainsmono.
